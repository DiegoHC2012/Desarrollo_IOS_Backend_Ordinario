# Desarrollo_IOS_Backend_Ordinario

Backend y Frontend para examen ordinario de desarrollo movil 2 (iOS)

## 📦 Proyecto

Este repositorio contiene:
- **Backend API** - API REST con Node.js, Express y Firebase
- **Frontend Admin** - Aplicación React para gestionar el backend

## 🚀 Backend API

Backend construido con Node.js, Express y Firebase para gestionar:
- Autenticación de usuarios
- Anuncios institucionales
- Materias de estudiantes
- Tareas y calificaciones
- Perfiles de estudiantes

### Instalación y Uso

```bash
# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Build
npm run build

# Producción
npm start

# Tests
npm test
```

## 🎨 Frontend React

Aplicación web moderna para administrar todas las funcionalidades del backend.

### Características
- ✅ Autenticación con Firebase
- ✅ Dashboard de configuración
- ✅ CRUD completo para todos los módulos
- ✅ Diseño responsive
- ✅ Validaciones y manejo de errores

### Quick Start

```bash
cd client
npm install
npm run dev
```
